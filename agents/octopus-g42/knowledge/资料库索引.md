# Rusted Warfare Agent 游戏资料库索引

用途：为铁锈战争 Agent 的逆向、World Model、地图理解、经济、Replay、网络与测试提供统一资料入口。

## 使用原则
1. 原始资料不修改；发现错误统一写入 `90_勘误与已核验事实/ERRATA.md`。
2. 社区文档用于发现字段名、机制和验证方向，不直接等同于当前 1.15 实际真值。
3. 优先查现有资料，再新增反射探针；危险或未知引擎调用不得仅凭名字猜测。
4. Live 决策只使用当前玩家合法可见的信息；离线资料只定义公共规则和能力，不泄露动态迷雾真值。
5. GitHub 原始仓库保留 `.git`，可 `git pull` 更新；不要在 clone 内保存我们的补丁或勘误。

- `00_版本基线`：当前游戏/Agent 版本、SHA 和环境说明。

- `20_整理与结构化资料`：清洗文本、JSON、结构化表和核验报告。
- `30_GitHub原始仓库`：外部开源仓库的完整 clone 与 HEAD 记录。

- `50_Replay资料`：Replay 样本、解析记录、checksum 调查材料。
- `90_勘误与已核验事实`：我们的纠错和高可信事实。

## 证据等级（项目约定）
- E0：观察/线索。
- E1：可检查 trace、源码或字节码证据。
- E2：可复现脚本/确定性测试。
- E3：独立交叉验证。
- E4：真实原生游戏行为验收。
社区资料即使很详细，也不自动获得 E2/E3/E4；结构化转写继承原始来源的不确定性。
## Codex/工程 Agent 推荐检索顺序
`README索引 → ERRATA → VERIFIED_FACTS → Tape/rw_analysis → 反编译源码 → 社区语义表 → 只读探针/实机验证`

若资料冲突：保留冲突，不擅自合并，以当前冻结版本的源码/字节码/安全实测为最终裁决。

## 当前最值得补的资料（按优先级）
1. **原版 1.15 maps + tilesets 的索引/抽取**：其实冻结原版环境里已经存在完整 TMX，不必再外找；下一步只需把常用1v1地图和依赖做索引或抽取到 `40_地图与单位原始数据`。
2. **1.15 原版单位能力真值**：后续从当前冻结 game-lib/菜单/安全运行时生成 `verified_unit_catalog.json`，不要继续依赖社区价格表。
3. **Replay 样本集**：正常胜负、无胜负、断连、host结束、resync、不同地图；用于 parser/checksum 与战后分析。

## 不急着补
- 更多未经验证的单位价格表：边际价值低且容易互相抄错。
- 大量重复反编译仓库：目前 7 个核心 GitHub 源已覆盖主要方向。
- 与铁锈无关的通用 LLM/RTS 项目：等上层模型决策真正接入时再收。
- 大量 Mod：除非用于验证特定字段语义，否则会增加版本/规则噪声。
