# Codex：World Model v0.1 + Recon v0 下一轮合同（2026-09-27）

当前基线：`HANDOFF_Codex_vNext_World_Model_v0_2026-09-27.md` 已完成 World Model v0，本轮可直接继续，不要求先等 DeepSeek 独立验收。
用户希望今天继续推进，并明确接受由 Codex 自行裁剪 v0 深度、安排子智能体；但目标必须出现真实可见的 Agent 行为变化，而不是只新增日志。

## 1. 核心目标
把现有 `enemyIntel` 从“记住合法见过的敌人”推进到“能基于历史情报主动侦察”。
至少争取在真实局中看到一次完整闭环：
**敌方建筑合法可见 → 进入迷雾成为 LOST_CONTACT → 生成侦察任务 → 某单位主动前往最后已知区域 → 合法重获视野 → 更新/清理情报。**

## 2. 统一 Recon 角色思想
“侦察”不是固定单位类型，而是一种任务角色。正规侦察者与被主力淘汰的残血单位，都可进入同一 Recon Controller。
建议最少支持三类任务语义：
- `RECHECK_INTEL`：复查失联建筑/高价值目标最后已知位置；
- `FRONTIER_SWEEP`：探索长期未见/未知的深雾区域；
- `SUICIDE_PROBE`：单位已高概率无法安全撤离时，以死亡前最大信息增益为目标深入侦察。

## 3. enemyIntel 状态
现有 `VISIBLE / LOST_CONTACT` 保留。
若侦察单位已让旧坐标及必要邻域重新进入合法视野、而目标未出现，可增加 `CLEARED`/等价语义；不要把“没看见”直接写成 `CONFIRMED_DEAD`。
仅在有明确死亡证据时才允许 `CONFIRMED_DEAD`。隐藏期间不得继续读取敌方真实位置/HP/状态。
## 4. 正规侦察者与“开除队籍”
用户希望提前储备侦察能力，但不要硬编码“永远 N 台”。建议做成 Recon Capacity / demand：有高价值失联目标、深雾或大图需求时维持侦察者；EMERGENCY 时可停止补充。
正规侦察者优先承担 `RECHECK_INTEL`，目标是活着获取信息。
残血战斗单位在继续留主力的战斗价值低于其信息价值时，可从 MAIN_FORCE “开除队籍”，转为 `EXPENDABLE_SCOUT`；转岗后不再按正常主力逻辑使用。
当正规侦察者低血/转为 expendable 后，应降低有效 Recon Capacity，并在经济允许时产生补侦察者需求。

## 5. Map Memory / 深雾
如果当前合法信息足够，建议新增轻量地图记忆：`UNKNOWN / EXPLORED / VISIBLE`（或等价语义）及 lastSeenTime。
`FRONTIER_SWEEP` 不应反复探“浅雾”，而应优先长期未见、未知面积大、信息陈旧度高的“深雾/雾与已探索地表边界”。
残血 expendable 单位特别适合执行此类高风险扫雾。

## 6. Threat / Evade / Suicide
侦察者正常策略应尽量沿已知威胁边缘获得视野，而非机械直线撞敌。
区分敌方“视野、攻击范围、移动速度/追击能力”；绝对禁止依赖雾中真实敌位，只能使用当前可见与合法记忆/公开单位属性。
若被锁定/持续受击，进入 `EVADE`：优先向我方安全势力场撤退（战斗单位密度、炮塔/基地/维修点、远离已知威胁），不要只按单位数量把追兵引进脆弱经济区。
确认安全后可回待命/再次侦察。若退路被封或敌方明显更快、存活概率很低，则允许切换 `SUICIDE_PROBE`，选择能最大化新视野/深雾揭示的方向穿入，而不是原地送死。
对明显更慢的敌方威胁，优先绕攻击/追击边界而不是正面撞入。

## 7. 优先级与边界
本轮主任务是“记忆真正驱动侦察行为”。不要同时大改经济、复杂兵种克制、多人/self-play 或豪华 UI。
原生 replay frame 6452 checksum 分叉可作为只读/实验副线继续定位，但不能抢主线程；失败实验不得进入正式 runner。
允许 Codex 自行决定先实现哪些子集、是否拆子智能体；仍保持一个代码 owner，其余尽量只读。发现风险时优先收束成可验证闭环。
## 8. 验收期望
优先争取以下可观察证据，而不是只给单测：
1. 至少一场真实原生/headless 局出现 `LOST_CONTACT` 高价值建筑，并生成侦察任务；
2. 能指出执行侦察的单位是谁、为何被选为正规 Scout 或 expendable；
3. 单位到达后通过合法视野产生 `reacquired` 或 `cleared` 结果；
4. 若触发 EVADE / expendable / suicide 中任一分支，给出事件时间线；若没自然触发，不要造假；
5. 当前战术/经济未被无意破坏，完整回归通过。

不要为了跑通验收去注入隐藏敌情、直接写未知引擎字段或人工伪造 LOST_CONTACT。
如果真实随机局很难自然覆盖完整链，可以用已有测试夹具做 E2，再至少用真实局验证行为片段；明确区分证据等级。
