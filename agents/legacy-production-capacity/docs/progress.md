## 接下来优先顺序

1. 用户 Windows 上以最终包完成 Match 实机验收，确认画面结算与 battle JSONL 一致。
2. 九图轮换、小规模重复评估，单独记录完整胜利、完整失败、限时、接口错误、无效日志；不把所有 PASS 算成胜利。
3. 统一持续经济扩张与战斗调度，增加建造者/工厂损失后的恢复、修理、防空组合、拥堵及搜索收尾处理。
4. 固定开局设置和随机种子的可重现性；全局 APM、反应延迟约束；异常自动恢复。
5. 在稳定对局和数据规范上再开发真人回放解析、行为克隆、历史对手池与自我博弈。当前没有学习模型。

原方案 0.1～0.9 是成熟度等级，0.07-alpha1 是软件交付版本。现在已有 0.1 完整对局原型与部分 0.3 战术组件，尚不能宣称稳定 0.3、更强于原版 AI 或任何真人竞技水平。
